About the model

  • Single-chirp SNR uses the radar equation with chirp energy: SNR = Pt·Gt·Gr·λ²·σ·Tc / ((4π)³·R4·k·Ts·L).
  • Needed SNR: Albersheim's equation (Swerling 0) and the exact Swerling 1 single-pulse result. Coherent integration subtracts 10·log10N.
  • CFAR loss uses the cell-averaging formula for Swerling 1. Binary and CPI M-of-N use binomial statistics, with an exact Marcum-Q step for binary.
  • Multipath is a flat-Earth two-ray model with Fresnel reflection (land εr 15, sea εr 80). Clutter uses a constant-γ model.
  • Rough estimates: ADC quantization (−15 dBm max input mapped to full scale at 0 dB gain), atmosphere, rain (ITU-R P.838 values), scan loss.
  • Use it to learn and compare designs. Confirm final numbers in MATLAB Radar Designer.
